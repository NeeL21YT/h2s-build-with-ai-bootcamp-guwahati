# H2S × Google — Build with AI Bootcamps 2026 · Guwahati

Landing page for the **Build with AI Bootcamp — Guwahati** edition, organized by Hack2Skill in partnership with Google.

Built with React + Vite and the **Orbital Precision** design system — a deep-space dark theme with neon violet and electric cyan accents, glassmorphism panels, and scroll-reveal animations.

---

## Sections

- **Hero** — Live mission dashboard with animated telemetry metrics
- **Features** — 6 platform capabilities in a bento grid
- **How It Works** — 4-step onboarding flow (2×2 card layout)
- **Process** — Interactive phase tabs: Onboard → Configure → Deploy → Operate
- **Telemetry** — Live cluster console with real-time status table
- **Integrations** — 12 native integrations chip grid
- **Pricing** — 3-tier plan cards with featured highlight
- **FAQ** — 2-column accordion with platform-specific Q&A
- **CTA + Footer** — Conversion section and multi-column footer

---

## Stack

- React 19 + Vite 8
- Tailwind CSS v4 (`@tailwindcss/vite`)
- Orbital Precision design system — deep space dark, neon violet `#A855F7`, electric cyan `#38BDF8`
- Fonts: Sora · Plus Jakarta Sans · JetBrains Mono

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)
